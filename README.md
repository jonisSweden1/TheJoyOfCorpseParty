# The Joy Of Corpse Party

The Joy of Corpse Party is a game made by Jonathan Sandström.

This game is a Five Nights at Freddy's fan game that was remastered in 3D from 10 years ago. Around 2017, the new game project called The Joy of Corpse Party was made in ClickTeam Fusion 2.5. The rendering of the game was made in Source Filmmaker. These tool combinations did work at the start of the project. However, these would not work out in the end, as Source Filmmaker would frequently crash in the same session, and the project became too disorganized. The project would eventually end after two years in development.

As a result, a remastered version was initiated, but this time, made in Unity 6.5. Initialized last year, the plan was to resurrect the game from what the project was in the beginning. This time around, there are new features that were added, thanks to the 3D space. Now the project is still in early access, as it is going through development of different, small and big updates on the horizon. These updates will include new aspects of the prototype that will provide feedback from the players on Itch.io and Gamejolt. 

As of now, a new update, 0.4.0, is about to be released soon on Itch.io and Gamejolt. The update will include a working prototype of security gameplay, as well as a new main menu, a new pause menu, and new 3D models for decorations and for the player's flashlight.

I hope to bring this game to Itch.io and Gamejolt soon, as well as the other project I'm passionate about, which is Fast Food Simulator.
